A 4 KB chess engine in pure Python: 0x88-board alpha-beta with quiescence search, Michniewski piece-square evaluation, Zobrist transposition table, killer + history move ordering, and iterative deepening on a fixed 60,000-node budget — deterministic, stdlib only, no model calls. Practice Elo ~1,190 (floor to reach the final: 1,154).

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
